Commande d'abord

Le catalogue ouvrira avec les premières commandes

Avant d'afficher un catalogue complet, Bouguenais Ludique fonctionne sur demande : vous indiquez ce que vous cherchez, je vérifie les possibilités, puis la commande est confirmée ensemble.

Pourquoi pas encore de catalogue ouvert ?

L'objectif est de construire l'offre à partir des vraies demandes, sans afficher une sélection qui ne serait pas encore disponible. Les premiers retours permettent de prioriser les univers, les références et les quantités utiles.

Parcours de commande proposé

1

Exprimer le besoin

Envoyez le jeu, l'univers ou le type de produit recherché : jeu familial, expert, TCG, puzzle, échecs ou idée cadeau.

2

Vérification

Je confirme la disponibilité possible, le prix estimé, le délai et les alternatives pertinentes si la référence exacte n'est pas adaptée.

3

Validation

La commande est retenue uniquement après accord clair sur le produit, le prix et les modalités de remise en main propre.

4

Retrait local

Le retrait se fait à Bouguenais, sur un créneau convenu ensemble. La commande contribue ensuite au baromètre du projet.

Pour lancer une demande, indiquez simplement le jeu recherché, le budget approximatif et vos contraintes éventuelles.
